# 春风精神病院 / 基础底稿

这里存放《春风》公开版的基础文本。目标是把原本绑定固定主角的版本改造成可由任意玩家填写 `{user}` 资料后直接使用的通用底稿。

## 脱敏原则

- 不保留固定主角姓名。
- 不保留原作者角色的年龄、身高、职业、学校、住房、车辆、宠物、外貌、恋爱史、择偶偏好等默认资料。
- 不从作者现实信息、旧聊天或原版固定主角档案回填 `{user}`。
- 玩家没有填写的字段保持未知。
- 与年龄、体重、前任、择偶标准等有关的剧情钩子全部改成**条件触发**：只有玩家在当前游戏里主动提供过对应素材，NPC 才能调用。
- 保留《春风》的核心机制：双向误读、情境复写、现实版 / 复写版分账、三男主独立动机、毒电波演出、八周结构与多结局。

## 文件

- `01_春风_主持底稿_user通用版.md`：完整主持规则、时间线、数值、三男主路线、VR 与结局。
- `02_春风_角色卡_user通用版.md`：世界地点、NPC 卡、男主卡与通用 `{user}` 资料入口。
- `03_男主同步视角补丁_user通用版.md`：玩家可见的男主同期内部视点规则。

## 使用方式

开局时让玩家只填写愿意填写的资料。不要为了让原剧情“对上”而追问年龄、体重、恋爱史等字段；缺少某个素材时，对应事件直接跳过或换用玩家已经主动提供的其他素材。
